RDG — все исходные файлы без папок.

ОСНОВНОЙ ЗАПУСК (сайт): run.py
ТЕЛЕГРАМ-БОТ (отдельный процесс): bot_run.py
ЗАВИСИМОСТИ: requirements.txt
СБОРКА: Dockerfile

Файлы app__*.py и static__* — отдельные исходники для просмотра и редактирования. Их содержимое уже встроено в run.py. Их НЕ нужно импортировать напрямую и НЕ требуется все загружать в Bothost для запуска этой упакованной версии.

Загрузка веб-приложения: run.py + requirements.txt + Dockerfile.
Для запуска бота нужен отдельный процесс с командой python bot_run.py (если панель Bothost позволяет отдельный сервис); этот процесс нуждается в run.py и requirements.txt. Сам Dockerfile запускает только сайт.

Важно: переменные BOT_TOKEN, PUBLIC_URL, FOOTBALL_API_KEY задаются отдельно в Bothost, не помещайте секреты в архив. Для сохранения базы задайте DB_PATH в постоянном каталоге, например /app/data/football.sqlite3, только если Bothost гарантирует постоянное хранилище там. Не заменяйте существующую базу.
